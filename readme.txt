burn-this-cloth
---------------
 
An interactive cloth-burning simulation built with
JavaScript, PixiJS, and WebGL.

[Live Demo](https://ramedhis.github.io/burn-this-cloth/)
 
Hover or move your pointer over the canvas to push and
deform the fabric, then click a spot to set it on fire.
Swipe fast for a wind gust.
 
> To use locally, open [index.html] in a browser.
